# Шаблон сайта для клининговой компании

Готовый многостраничный сайт для продажи клининговым бизнесам. Чистый **HTML/CSS/JS** — без сборки, фреймворков и зависимостей: папку можно залить на любой хостинг как есть.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Главная: hero, преимущества, услуги, шаги, отзывы, призыв к действию |
| `services.html` | Подробные услуги: описание, что входит, цена, время |
| `prices.html` | Прайс-лист + интерактивный калькулятор стоимости |
| `gallery.html` | Слайдеры «До/После» + сетка фотографий |
| `contacts.html` | Форма заявки (с валидацией и маской телефона), контакты, карта |
| `privacy.html` | Политика конфиденциальности |
| `css/style.css` | Все стили (обычно не нужно трогать) |
| `js/settings.js` | **Единственный файл для адаптации под клиента** |
| `js/app.js` | Движок сайта (обычно не нужно трогать) |
| `img/` | Иллюстрации и фото (заменяются на реальные) |

## Быстрый старт

1. Откройте `index.html` в браузере — сайт уже работает с демо-данными.
2. Для локального просмотра с формой и слайдерами лучше запускать через сервер:
   ```
   python -m http.server 8080
   ```
   и открыть `http://localhost:8080` (или просто использовать расширение Live Server в VS Code).
3. Всё содержимое сайта задаётся в **`js/settings.js`** — адаптация под нового клиента занимает 15–30 минут.

## Адаптация под клиента (js/settings.js)

Пройдитесь сверху вниз по файлу:

1. **`brand`** — название компании и логотип. Если есть свой логотип — положите файл в `img/` и укажите путь в `brand.logoImage`.
2. **`contact`** — телефон (двумя строками: для показа и для звонка), почта, адрес, часы работы, Telegram/WhatsApp.
3. **`theme`** — два цвета: основной (кнопки, акценты) и дополнительный. Меняйте — весь сайт перекрашивается.
4. **`hero`** — заголовок первого экрана, подпись, кнопки, цифры-статистика.
5. **`advantages`** — 4 карточки преимуществ.
6. **`services`** — список услуг: название, описание, что входит (`includes`), цена, время. Поле `id` используется в калькуляторе и форме — давайте услугам уникальные латинские `id`.
7. **`steps`** — шаги работы.
8. **`reviews`** — реальные отзывы клиентов (имя, дата, оценка 1–5, текст, услуга).
9. **`calculator`** — цены за м² и минимальные заказы по типам уборки, доп. опции, скидка за регулярность. Названия типов уборки здесь и в `services` должны совпадать по смыслу.
10. **`gallery`** — ссылки на фото «до/после» и сетку фотографий.
11. **`form`** — тексты благодарности (эндпоинт — см. ниже).
12. **`seo`** — заголовки и описания страниц для Google/Яндекса.

## Замена фотографий

Демо-иллюстрации лежат в `img/` (SVG). Чтобы поставить реальные фото:

- положите файлы в `img/`, например `before-1.jpg`, `after-1.jpg` (рекомендуется ширина 1200px, пропорция ~12:7);
- укажите новые пути в `settings.js` → `gallery.beforeAfter` и `gallery.photos`, а также `hero.image`.

Слайдер «до/после» работает с любыми фотографиями одинаковой пропорции.

## Подключение отправки заявок

По умолчанию форма работает в **демо-режиме** (ничего никуда не отправляется, заявка видна в консоли браузера). Варианты подключения:

### Formspree (проще всего, бесплатно до 50 заявок/мес)
1. Зарегистрируйтесь на [formspree.io](https://formspree.io) и создайте форму — получите адрес вида `https://formspree.io/f/xxxxxxx`.
2. В `settings.js` впишите: `form: { endpoint: "https://formspree.io/f/xxxxxxx", ... }`.
3. Заявки будут приходить на вашу почту.

### Telegram-бот
Проще всего через промежуточный сервис (например, интеграцию Formspree → webhook), либо попросите разработчика заменить `fetch` в `js/app.js` (функция `initForm`) на отправку в API Telegram.

## Публикация на хостинге

- **Обычный хостинг (Timeweb, Beget, REG.RU…):** загрузите содержимое папки в корень сайта по FTP/панели. Готово.
- **Netlify / Vercel (бесплатно):** перетащите папку в Netlify Drop или подключите Git-репозиторий.
- **GitHub Pages:** положите файлы в репозиторий, включите Pages в настройках.
- Замените `ЧистоДом`-домен демо-ссылок в `contact` на реальные перед публикацией.
